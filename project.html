Project Description

Information about the project

The Smart Home Security Assessment tool is a cybersecurity-focused application that is designed to help homeowners keep their home safe and secure while allowing for an easy way to assess their network security. Our sponsor, Thomas Mounts II, is interested in developing a solution that can make smart home security assessments more accessible and easier for everyday non-technical users to understand.

As smart home IoT devices become more popular in today’s world, homes can contain a wide variety of connected devices, which can lead to potential vulnerabilities within a home network. Each connected device can potentially introduce security risks if it has outdated software, misconfigured ports, or other security weaknesses.

This is where our tool comes into play. The Smart Home Security Assessment Tool will allow users to scan their home network to identify connected devices, assess potential security risks, and generate a report card showing the overall security of their home network. The report will also explain vulnerabilities that were discovered and provide recommendations for measures that could be taken to create a more secure home.

High Level Requirements

Overview of the project's main requirements.

  • Network Discovery – The application must be able to identify all devices connect to a home network and store it while also making sure it's not scanning any networks without authorization
  • Security Assessment – The application must be able to analyze discovered devices for potential security risks and vulnerabilities and rank the severity of the issue.
  • Vulnerabilty Reporting – The application must be able to clearly identify security issues and provide information about the impact of each vulnerability to the user and also generate a summary of what was found.
  • Recommendations – The application must be able to provide users with actionable recommendations for addressing vulnerabilities and it must explain the vulnerabilities in a way for non-technical users to understand.
  • User-Friendly – The application must be able to provide a straightforward interface for starting an assessment and must also provide a clear and organized format.

How the System Works
1. Network Scan

The user launches the application and authorizes a network scan on their home network. The tool then scans the network to identify connected devices and gather relevant network information. The system will also provide a network map that inventories the connections between devices and the router.

2. Network Analysis

The collected network information is analyzed to identify potential security vulnerabilities. The tool keeps a list of discovered devices and uses the gathered information to begin evaluating the security of the network.

3. Security Assessment

The tool evaluates the discovered devices and formulates a security assessment score based on the vulnerabilities and security risks that are identified.

4. Security Report

The tool generates a security report card that presents the overall security assessment. Any vulnerabilities that are discovered will be described in a clear and digestible format so that users can understand the risks within their home network.

5. Recommendations

The tool provides recommendations based on the severity of each vulnerability. Users will receive actionable steps explaining how they can address identified issues and improve the security of their smart home network.
