Project Introduction

Learn more about the project the Secure Jacks team is working on.

The Smart Home Security Assessment Tool provides homeowners with an accessible way to assess the security of thier smart home network. The application scans connected devices, identifies potential vulnerabilities, and generates a security report that explains discovered risks and provides actionable recommendations for improving network security.

Project Sponsor

Thomas Mounts II

Thomas Mounts II proposed the Smart Home Security Assessment Tool project to the Secure Jacks team as a personal project to help homeowners assess the security of their connected devices to their smart home network. Currently, Thomas resides in Charlotte, North Carolina and the Secure Jacks team is excited to develop a solution that will allow for greater visibility into complicated, security risks that homeowners may not be aware of.
