Resources

Overview of the project's main resources.

  • Router – Self-contained access point for an isolated test network.
  • Ethernet Cables – Wired connections between the router and development machines.
  • IoT Devices – Consumer smart home devices (smart plugs, lights, cameras, etc.) to scan and assess.
  • USB Drive – Portable storage for the application, test data, and demo files.
  • Wi-Fi Plan – Internet service for the test network.
